01 · Custom Forge App Development

From scattered billing ops to one app embedded in Jira.

Jira Software Forge Forge MCP TWG CLI Claude Code Claude Agent for Jira

Background

Billing for our own services and licenses ran on a patchwork of Jira automations, external scripts, and manual steps. We aren't an app-building business — our only app experience was building legacy Data Center apps — but invoicing and quoting volume had grown steadily for years, and Jira was already the hub tracking all of it. The result was an invoicing system cluttered with multiple draft estimates and invoices for the same deal.

Solution

We used Claude Code with Forge MCP to build a custom app embedded directly in our Jira instance. Plugging in the Teamwork Graph CLI and Rovo MCP feeds the app context straight from Jira tasks and related knowledge, and a Claude agent built into the Jira workflow can make code changes directly from the board.

Client invoicing

  • Daily aggregation of work logs into mid-month client estimates
  • Auto-generated invoice line items from worklog detail
  • Invoice preview embedded directly in the Jira ticket
  • Invoice generation once the estimate is approved for sending

Resales

  • Intraday sync with PPC for new and updated quotes
  • Quote preview inside the Jira ticket
  • Automated sales order generation from Jira
  • Automated invoice generation from Jira

Outcomes

  • A much smoother process — no switching tools or waiting on background automations
  • A cleaner invoicing system with a lower error rate
  • A significant drop in automation usage and noise from failed automation runs

02 · Agentic Workflows

Agents that work inside existing processes, not around them.

Rather than standing up new tools, we plugged agents directly into the workflow steps we already had — creating, reviewing, and handing off work without giving anyone something new to learn.

Jira Confluence Rovo Software Work Management

Recurring task creation

A Rovo agent scans Confluence process docs daily and creates matching work items — assignees, details, and even fuzzy recurrences like "every odd year."

AI intake

An agent reads invoice PDFs and populates the matching work item directly — faster intake, fewer manual entry errors.

Review

A second agent checks items like bills and invoices for common errors before they move forward, catching problems earlier.

Handoff

Agents watch work-item status and hand off automatically, updating status and assignee so the next step starts itself.

04 · AI Governance

Guardrails that scale with the agents.

More agents means more surface area — so governance is built in, not bolted on afterward.

  • Documented agent best practices — covering both development and testing
  • A central agent registry — so every agent in production is accounted for
  • An audit agent — compares our policies against actual implementation and generates an audit report plus Jira tasks for any gaps
  • An Atlassian AI security guide — the same guide we share with clients
